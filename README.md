# Mealy Machine

A C-style block comment starts with /* and ends with */.

| Input string | result | reason |
| :--- | :--- | :--- |
| /*aa*/ | accepted | valid comment containing text |
| a*/ | rejected | No opening /* |


Our machine must check two things:
1. The input starts with /*.
2. The input ends with */, with no extra characters after the closing delimiter.
